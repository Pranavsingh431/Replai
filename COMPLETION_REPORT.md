## 🏗️ Architecture Highlights

### The Moat (Competitive Advantage)
```
contacts.tone_profile_json
├── emoji_usage
├── humor
├── formality
├── response_speed
├── topics_that_work
├── topics_that_failed
└── communication_patterns
```

**This memory system is what makes the product defensible.**

### The State Engine
```
Every conversation classified into:
├── Attraction Score (-100 to +100)
├── Stage (cold → warm → flirting → rapport → intimate → dying)
├── Dominant Tone (playful, formal, teasing, etc.)
└── Ghosting Risk (low, medium, high)
```

**This context awareness is what ChatGPT doesn't have.**

### The Reply System
```
3 AI-generated options:
├── Safe: Low-risk, friendly, keeps conversation going
├── Flirty: Playful, teasing, builds attraction
└── Bold: Direct, confident, moves things forward
```

**This choice architecture reduces decision paralysis.**
