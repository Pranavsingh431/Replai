# 🎯 How to Use Replai - Complete Guide

## 🚀 Quick Start (5 Minutes)

### **Step 1: Open the App**
```
http://localhost:3000
```

### **Step 2: Create Account**
1. Click "Sign up"
2. Enter:
   - Display Name: Your Name
   - Email: you@example.com
   - Password: YourPassword123
3. Click "Create Account"
4. You now have **10 free credits**! 🎉

### **Step 3: Add Your Profile** (Recommended)
1. Click the **Settings icon** (⚙️) in top bar
2. Enter your bio/profile:
   ```
   Software engineer who loves hiking and photography.
   Looking to meet creative people who enjoy outdoor adventures.
   ```
3. Click "Save & Analyze"
4. AI extracts your personality and communication style

### **Step 4: Create Your First Contact**
1. Click **"+ Add Contact"** button
2. Fill in:
   - **Name**: Sarah
   - **Platform**: Tinder
   - **Their Profile** (optional):
     ```
     Adventure seeker, coffee enthusiast, always up for trying new restaurants
     ```
3. Click "Add Contact"
4. AI analyzes their personality too!

### **Step 5: Start a Conversation**
1. Click on **Sarah** in your contacts list
2. You'll see the conversation view
3. Select sender: **"Them"** (Sarah)
4. Type: `Hey! How's it going?`
5. Click Send (or press Enter)
6. Switch sender to **"You"**
7. Type: `Hey! Pretty good, how about you?`
8. Add a few more back-and-forth messages

### **Step 6: Generate AI Replies** (Uses 1 Credit)
1. Click **"Generate Replies"** button
2. Wait 5-10 seconds
3. See **3 AI-generated options**:
   - **Safe**: Low-risk, friendly
   - **Flirty**: Playful, builds attraction
   - **Bold**: Direct, moves things forward
4. Click the **copy icon** on any reply
5. Paste it in your real conversation!

### **Step 7: Buy More Credits** (When You Run Out)
1. Click **"Buy Credits"** in top bar
2. Choose a plan:
   - 20 credits → ₹99
   - 100 credits → ₹399 (best value)
   - Unlimited 7 days → ₹699
3. Click "Purchase"
4. Complete payment on Stripe
5. Credits added instantly!

### **Step 8: Try Dark Mode**
1. Click the **Moon icon** (🌙) in top bar
2. UI switches to dark mode
3. Click **Sun icon** (☀️) to switch back
4. Preference is saved

## 💡 Pro Tips

### **Better Replies with Profiles**
- Add your own profile → AI matches your style
- Add contact profiles → AI references their interests
- More context = better, more personalized replies

### **Understanding the Scores**
- **Interest Score**: -100 (not interested) to +100 (very interested)
- **Stage**: cold → warm → flirting → rapport → intimate
- Higher scores = more engaged conversation

### **When to Use Each Reply**
- **Safe**: When unsure, keeping conversation alive

- **Bold**: When ready to move forward (ask for date/number)

- 10 free credits to start

## 🧠 How the AI Works

### **1. Profile Analysis**
When you add a profile (yours or theirs):
```
Input: "Software engineer who loves hiking..."

AI Extracts:
- Personality: Adventurous, tech-savvy
- Interests: Hiking, photography, technology
- Communication style: Casual, friendly
- Intent: Dating, meeting creative people
```

### **2. Conversation Classification**
After each conversation:
```
AI Analyzes:
- Attraction score (how interested they are)
- Relationship stage (cold → intimate)
- Dominant tone (playful, formal, etc.)
- Ghosting risk (low, medium, high)
```

### **3. Memory System**
Over time, AI learns:
```
- How they use emojis
- Their humor style
- Response speed
- Topics that work
- Topics that failed
```

### **4. Reply Generation**
Uses ALL context:
```
- Your profile
- Their profile
- Conversation history
- Relationship stage
- Memory patterns

Result: Highly personalized, non-generic replies
```

## 🐛 Troubleshooting

### **"Insufficient credits" Error**
- You've used all your credits
- Click "Buy Credits" to purchase more
- Or wait for a promotion/refill

### **"Failed to generate replies" Error**
- Check your internet connection
- Make sure you have credits
- Try again in a few seconds
- Contact support if persists

### **Contact Not Showing**
- Refresh the page
- Check if you're logged in
- Try creating the contact again

### **Dark Mode Not Working**
- Click the Moon/Sun icon in top bar
- Refresh if needed
- Check browser console for errors
